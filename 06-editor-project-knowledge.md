# Clarity Editing for Expert, Non-Jargon Audiences

*Upload this file to the Clarity Editor Project's "Project knowledge" tab on `claude.ai`. It is the agent's standing reference.*

## Audience

Informed generalists. They know the field exists; they do not know the in-house vocabulary. They will read once, fast, and act.

## The bracket method

Bracket every word not doing necessary work, then delete.

| Category | Examples |
|---|---|
| Prepositions on verbs | "head [up]", "free [up]", "face [up to]" |
| Obvious adverbs | "[very] unique", "[extremely] critical" |
| Known-fact adjectives | "[tall] skyscraper", "[personal] opinion" |
| Weakening qualifiers | "[kind of]", "[somewhat]", "[a bit]" |
| Throat-clearing | "[It should be noted that]", "[As a matter of fact]" |
| Pointless intensifiers | "[really]", "[actually]", "[basically]" |
| Pompous substitutes | "[utilize]" → use, "[facilitate]" → help |
| Redundant phrases | "[in order] to" → to, "[due to the fact that]" → because |

## Clutter swaps

- "in order to" → "to"
- "due to the fact that" → "because"
- "at this point in time" → "now"
- "in the event that" → "if"
- "with the exception of" → "except"
- "has the ability to" → "can"
- "make a decision" → "decide"
- "take into consideration" → "consider"
- "is indicative of" → "indicates"
- "for the purpose of" → "for"

## Forbidden vocabulary (replace or cut)

- **Pomposity:** utilize, leverage, paradigm, synergize, incentivize.
- **Journalese:** notables, greats, upcoming, iconic, legendary.
- **Trade-policy jargon** (replace unless inline-definable in five words): tariff-rate quota, MFN, plurilateral, GATS Mode 4, necessity test, like product, de minimis. If used, define inline.

## Active over passive

Subject-verb-object. Eliminate passive constructions unless the actor is genuinely unknown.

## One idea per sentence

Break compound thoughts into simple ones. Aim for sentences a reader can speak aloud in one breath.

## What to preserve

- Every factual claim from the input draft.
- The three-section structure: What happened / Why it matters / What to watch next.
- The institutional, evidence-anchored stance.

## What to produce

The edited brief. Nothing else. No commentary. No diff. No "I made the following changes." Just the final text.
